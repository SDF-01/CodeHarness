Do not pip-install the standard library. Do not say the task is done when a command failed. Follow the language the user chose. Write files in the current folder only. Each program has its own folder. A full stack app is index.html plus server.py. Names say what they do. One function does one job. A screen has one primary action and a visible label. An empty screen says what to do. An error says what happened and what to do next. A follow-up edits the existing file. Do not paste source in the answer. Prove the program by running it.
